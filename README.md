# Telegram Finance Tracker

Локальный бот для ручного учёта доходов и расходов в рублях. Python 3.13+, uv; база SQLite создаётся автоматически. Аналитические отчёты в эту версию не входят.

## Установка и запуск

```sh
uv sync --locked --dev
cp .env_example .env
```

Создайте тестового бота через Telegram @BotFather и впишите его токен в `.env` локально. Не отправляйте токен в чат и не добавляйте `.env` в Git. Для загрузки настроек и запуска используйте:

```sh
uv run --env-file .env fin-tracker
```

Альтернативный запуск того же приложения:

```sh
uv run --env-file .env python -m fin_tracker
```

`BOT_TOKEN` обязателен. `DATABASE_PATH` — путь SQLite, по умолчанию `data/finance.sqlite3`. Бот работает одним процессом через long polling. Остановка — Ctrl+C. Незавершённый ввод хранится в памяти и после перезапуска теряется; завершённые операции сохраняются.

## Пользовательская приёмка

Для проверки используйте отдельного тестового бота и отдельную базу, чтобы не затронуть свои записи. В `.env` задайте `DATABASE_PATH=data/acceptance.sqlite3` и запустите одну из команд выше. В Telegram откройте своего тестового бота и отправьте `/start`.

- Создайте расход 125 без тегов и комментария: в «Операции» видны 125,00 ₽ и дата начала по Москве. Создайте доход с двумя тегами и комментарием.
- На вводе суммы попробуйте 0, -1, 1., 1e3: бот остаётся на шаге суммы и объясняет формат. Попробуйте 0,01 и большую сумму.
- Вернитесь с тегов к сумме и затем вперёд: введённые данные сохранены. «Назад» от суммы открывает выбор типа. «Отменить» оставляет базу без новой записи.
- Начните новую операцию посреди другой: бот уведомляет о сбросе, старая запись не создаётся. Нажмите кнопки старого ввода: новый диалог не изменяется.
- Откройте свою операцию и отредактируйте тип, сумму, теги и комментарий. До завершения запись не изменяется; дата остаётся прежней. Отмена редактирования сохраняет исходную запись.
- На комментарии нажмите «Далее» без нового текста: прежний текст сохраняется. Введите другой текст: он заменяет прежний. «Очистить комментарий» и затем «Далее» сохраняют пустой комментарий; очистка с отменой сохраняет прежний. Проверьте очистку и при создании.
- В «Теги» создайте, переименуйте, архивируйте тег. Старые операции сохраняют его, новое имя отображается в истории, архивный тег не предлагается для новых назначений. Создайте то же имя: получите «Тег восстановлен из архива», связи сохраняются. Повтор активного имени с другим регистром и пробелами по краям отклоняется.
- Редактируйте запись с архивным тегом: изменение суммы сохраняет тег; снятие показывает предупреждение, повторно выбрать его до восстановления нельзя.
- Удалите операцию: она исчезает, её теги остаются.
- Быстро нажмите «Далее» несколько раз при сохранении создания и редактирования: действие применяется один раз. Проверьте старые кнопки после завершения, отмены и перезапуска: данные не меняются.

После автоматической проверки требуется явное подтверждение пользователя о результате этого списка. Отсутствие токена, Telegram или ответа означает ожидание приёмки.

## Хранение и резервная копия

Для резервного копирования остановите бот и скопируйте файл `DATABASE_PATH` в безопасное место. Возвращая прежнюю версию приложения, не удаляйте SQLite-файл. Перед изменениями схемы потребуется отдельная миграция; текущая версия создаёт новую схему при первом запуске.

## Автоматическая проверка

Для полной воспроизводимой проверки из корня проекта:

```sh
uv sync --locked --dev
.venv/bin/python -m tests.full_gate
```

Требуются Python 3.13+ и OpenSpec CLI в PATH. Команда выполняет строгую валидацию изменения OpenSpec, проверку синтаксиса, статический анализ ruff и все unit-, интеграционные и e2e-тесты. Пропуски, ожидаемые падения, пустой уровень или необнаруженный тест блокируют успех. Все сценарии функциональных спецификаций сверяются с автоматическими тестами.

Тесты работают с временными SQLite-файлами и подменяют только внешний Telegram API; реальный токен не нужен. Успешные автоматические проверки требуют отдельной пользовательской приёмки по чек-листу выше. Подробности и соответствие сценариев тестам находятся в `openspec/changes/add-telegram-finance-tracker/testing.md`.
