## Why

Пользователю нужен простой Telegram-бот для ручного учёта доходов и расходов с собственными тегами. Проект пока содержит только структуру Python-пакета; необходимо определить проверяемый объём первой реализации.

## What Changes

- Добавление, просмотр, редактирование и удаление операций в рублях через Telegram.
- Пошаговый ввод суммы, нескольких необязательных тегов и необязательного комментария с кнопками «Назад», «Отменить», «Далее».
- Дата операции фиксируется в момент начала ввода; незавершённая операция не сохраняется.
- Создание, переименование, архивирование и восстановление пользовательских тегов с сохранением истории.
- Локальное хранение в SQLite через SQLAlchemy и изоляция данных пользователей.
- Возможность получать данные по периоду и тегам для последующей аналитики; состав отчётов определяет напарник отдельно.
- Обязательный процесс apply (с независимым автором тестов) → verify (статический анализ, полный gate unit/integration/e2e и пользовательская приёмка) → archive; архивирование запрещено до успешных проверок и явного подтверждения пользователя.
- Вне объёма: банковский импорт, Web UI/Web App, рекомендации, готовые аналитические отчёты и зависимости для их расчёта.

## Capabilities

### New Capabilities
- `delivery-verification`: оркестрация apply → verify → archive, независимый автор тестов, последовательное покрытие unit/integration/e2e, обязательный full-gate и пользовательская приёмка перед архивированием.
- `transaction-management`: ручной ввод и управление операциями, точные суммы и навигация.
- `tag-management`: пользовательские теги, архивирование, восстановление и связи с операциями.
- `user-data-storage`: идентификация пользователей, надёжное хранение и выборка данных для аналитики.

### Modified Capabilities

Нет: существующих спецификаций нет.

## Impact

Затрагиваются точка запуска, конфигурация, модули bot/handlers и db, документация запуска и тесты. Используются уже объявленные aiogram и SQLAlchemy; зависимости аналитики не добавляются. Изменение не включает реализацию отчётов в модуле analytics.
